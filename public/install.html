Install Synop

Set up your own AI video summarizer in under 2 minutes.
Free. Open source. Privacy first.

1
Prerequisites
Check you have Node.js and git installed
→

Synop requires Node.js 20+ and git. Run these commands to verify:

# Check prerequisites node --version npm --version git --version

Need to install? Get Node.js from nodejs.org and git from git-scm.com.

2
Clone the Repository
Download Synop to your machine
→

Open a terminal and run:

git clone https://github.com/sharadvc/synop.git cd synop
3
Install Dependencies
Install npm packages
→

Install all required packages with npm:

npm install
4
Configure Environment
Set up API keys and database
→

Copy the example env file and add your API keys:

# Create env file cp .env.example .env

Open .env and add your keys. You'll need at least one AI provider:

# Get free credits at https://openrouter.ai/keys OPENROUTER_API_KEY=sk-or-your-key-here

OpenRouter gives you free credits to start. Clerk keys are optional — the app works without auth.

5
Initialize Database
Push the schema to SQLite
→

Synop uses SQLite — no server setup needed. Just push the schema:

npx prisma db push
6
Run Synop
Start the development server
→

Start the dev server and open your browser:

npm run dev

Then open http://localhost:3000 in your browser.

Paste any YouTube URL and get your first summary in seconds.
